## 1. Общие положения

1.1. Настоящая Политика описывает, какие данные обрабатывает десктопное приложение
     MAZLIVE Desktop, с какими целями, кому они передаются и как Пользователь может
     реализовать свои права.

1.2. MAZLIVE Desktop — это **клиентское приложение**, которое работает в связке с
     сервисом MAZLIVE. Часть данных приложение передаёт на серверы MAZLIVE
     (`https://mazlive.com` и `https://games.mazlive.com`). Обратите внимание:
     **не все данные хранятся только локально** — данные авторизации, события эфира
     и служебные запросы передаются на серверы сервиса.

1.3. Оператор данных — автор проекта MAZLIVE: MAZA PRODUCTION.

## 2. Какие данные обрабатываются

### 2.1. Учётные данные и данные аккаунта
- **Сессионный токен авторизации** (cookie `authjs.session-token`): получается при
  входе через кабинет MAZLIVE; используется для запросов к API и проверки подписки.
- **Данные профиля**, получаемые от сервера (`/api/auth/verify-subscription`):
  идентификатор пользователя (`userId`), имя (`name`), e-mail (`email`),
  изображение профиля (`image`).
- **Ник TikTok** (cookie `tiktok_username`): используется как идентификатор
  комнаты эфира.

### 2.2. Данные эфира (события TikTok)
Только при активной трансляции приложение получает от сервера события эфира
через Socket.IO (`games.mazlive.com`, namespace `/viewer`):
- события подарков (gift), лайков (like), подписок (follow), входа зрителей (join);
- **аватары зрителей** (для отображения в игре);
- никнеймы/идентификаторы зрителей, участвующих в событиях.
Эти данные передаются сервером MAZLIVE и используются для игровой механики
(«Царь горы»).

### 2.3. Токен комнаты (room token)
- Временный токен доступа к игровой комнате (JWT, срок ~15 минут) передаётся
  через запросы к API и хранится **только в оперативной памяти** процесса.
- Токен **не сохраняется на диск**, обновляется по таймеру (~каждые 12 минут).

### 2.4. Локально сохраняемые данные
Приложение хранит локально (технология `electron-store`):
- **токен сессии** и данные профиля — в файле `mazalive-auth` (с шифрованием);
- **настройки игры GTA** (правила реакций, параметры трассы) — в файле `mazalive-gta`;
- **cookie сессии** в хранилище сессии приложения.
Эти данные остаются на устройстве Пользователя и не синхронизируются
как отдельное хранилище, кроме случаев обращения к сервису MAZLIVE.

### 2.5. Служебные данные
- **Диагностические журналы** (console-логи) — формируются локально, используются
  для диагностики; в общем случае не передаются автоматически на сервер.
- **Проверка обновлений** — периодические запросы к `mazlive.com` за метаданными
  обновлений (файл `beta.yml`).

### 2.6. Данные, которые приложение НЕ собирает
- Приложение не запрашивает доступ к контактам, камере, микрофону, геолокации.
- Приложение не собирает платёжные данные — оплата происходит на стороне сайта.
- Приложение не внедряет DRM, телеметрию или механизмы удалённого управления.

## 3. Цели обработки

- Авторизация и поддержание сессии Пользователя.
- Проверка подписки и предоставление доступа к играм.
- Получение и обработка событий эфира для игровой механики.
- Сохранение пользовательских настроек между запусками.
- Доставка обновлений приложения.
- Диагностика и поддержка работоспособности (локальные логи).

---

## 4. Передача данных и получатели

Данные передаются следующим получателям:
- **Серверы MAZLIVE** (`mazlive.com`, `games.mazlive.com`) — для работы сервиса,
  авторизации, подписки и событий эфира.
- **Сторонние платформы (TikTok и др.)** — в объёме, необходимом для получения
  событий эфира через соответствующие сервисы (передача обеспечивается сервером
  MAZLIVE, а не напрямую приложением).
- **Сервис обновлений** — запросы за метаданными обновлений.

Приложение не продаёт персональные данные третьим лицам.

---

## 5. Сроки хранения

- **Токен сессии** — хранится локально и считается действительным до 30 дней
  (далее требуется повторный вход); удаляется при выходе из аккаунта.
- **room token** — только в памяти, до ~15 минут / до закрытия приложения.
- **Настройки игры** — до их удаления Пользователем или удаления приложения.
- **Сроки хранения на стороне сервиса MAZLIVE** — `[указать при необходимости]`
  (определяются политикой сервиса).

## 6. Права Пользователя и как обратиться

Пользователь вправе:
- запросить доступ к своим данным, их исправление или удаление;
- выйти из аккаунта, что очищает локальные данные сессии и cookie
  (приложение выполняет полную очистку хранилищ при выходе);
- удалить приложение и связанные локальные файлы.

Для реализации прав обратитесь к автору проекта MAZLIVE (MAZA PRODUCTION).

---

## 7. Безопасность

- Сессия хранится с шифрованием (electron-store).
- room token не записывается на диск.
- Изоляция контекста включена (`contextIsolation: true`, `nodeIntegration: false`).
- Внешние ссылки открываются только через системный браузер, навигация внутри
  приложения ограничена доверенными доменами.
