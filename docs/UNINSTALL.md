# Удаление (GTA-мод и приложение)

## 1. Удаление мода GTA (через приложение)

1. Закрой GTA (если запущена).
2. В карточке **«GTA V — Царь горы»** нажми **Удалить мод**.
3. Что происходит:
   - удаляются **только файлы MAZLIVE**: `scripts/MazLiveKOTH.dll`, `scripts/MazLiveKOTH/settings.ini`;
   - файл `.mazlive-install.json` удаляется;
   - папка `MazLiveKOTH/` удаляется, **если пуста** (папка `backups/` и `mod.log` остаются для безопасности);
   - если файл был **изменён пользователем** (хеш не совпал) — он **НЕ удаляется**, показывается конфликт.

## 2. Ручное удаление (fallback)

```powershell
powershell -ExecutionPolicy Bypass -File UNINSTALL.ps1 -GamePath "C:\...\Grand Theft Auto V"
```

## 3. Восстановление изменённых файлов

Бэкапы лежат в `<GTA>/scripts/MazLiveKOTH/backups/`.
Каждый бэкап — копия перезаписанного файла с таймстампом в имени (`<файл>.<дата>.bak`).

Чтобы вернуть оригинал вручную:
1. Открой `backups/`.
2. Найди нужный бэкап (по имени/дате).
3. Скопируй его обратно в исходное место (например, `scripts/MazLiveKOTH.dll`).

## 4. Удаление приложения

- Windows: «Параметры → Приложения → Mazlive Desktop → Удалить».
- Данные сессии хранятся в electron-store (`mazalive-auth`); при удалении приложения удаляются вместе с профилем.
- Файлы игры и мод удаляются **отдельно** (см. п.1) — приложение не трогает папку GTA при своём удалении.

## 5. Что удалятор НЕ делает

- Не удаляет файлы, которые вы меняли вручную.
- Не удаляет ScriptHookV / ScriptHookVDotNet (это ваш установленный софт, а не MAZLIVE).
- Не трогает файлы других модов.
