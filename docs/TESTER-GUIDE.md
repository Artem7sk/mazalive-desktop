# Инструкция для тестера

Спасибо, что тестируешь **Mazlive Desktop 2.0 Beta**! 🎯

## Что тестируем

1. **Старые HTML5-игры** — должны работать **как раньше** (главное!).
2. **GTA V «Царь горы»** — новая desktop-игра (мод + агент).

## Подготовка

- Windows 10/11 x64.
- Установленная **GTA V Legacy** + ScriptHookV + ScriptHookVDotNet 3.
- Аккаунт **Pro** на mazlive.com.
- Тестовый EXE `Mazlive Desktop-2.0.0-beta.1.exe` (из GitHub Actions).

## Чек-лист тестирования

### A. Регресс старых игр (ОБЯЗАТЕЛЬНО, ≥5 игр)
Для каждой игры: запуск → окно игры открылось → подарки/лайки видно.

- [ ] territory-wars (Правители территорий)
- [ ] tower-siege (Осада башни)
- [ ] avatar-battle
- [ ] FlagPong
- [ ] tiktok-race
- [ ] (опц.) любая другая

### B. Авторизация
- [ ] Логин через приложение работает.
- [ ] Неверный тариф → сообщение о подписке.
- [ ] Logout → окно логина.

### C. GTA (desktop-game)
- [ ] «Проверить GTA» находит игру.
- [ ] Запуск **без установленной GTA** → понятная инструкция, приложение **не падает**.
- [ ] Запуск **без установленного мода** → предложение установить.
- [ ] Установка мода → файлы на месте.
- [ ] Запуск агента → соединение устанавливается.
- [ ] Socket.IO подключён (панель: «подключено»).
- [ ] Подарок (gift) → действие.
- [ ] Лайки (like) → ускорение.
- [ ] Подписка (follow) → щит.
- [ ] repeatEnd (streak-подарок) учитывается.
- [ ] Дедупликация: дубль события не создаёт второй объект.
- [ ] Потеря соединения → переподключение.
- [ ] Остановка игры.
- [ ] Удаление мода → только файлы MAZLIVE.
- [ ] Обновление приложения (electron-updater).
- [ ] Обновление мода (по подтверждению).
- [ ] Deep link `mazalive://launch?game=gta-koth&room=<id>`.

## Как сообщать о проблемах

Пришли:
1. Что делал (шаги).
2. Что ожидал.
3. Что получилось (скриншот).
4. Логи: панель → «Журнал», `<GTA>/scripts/MazLiveKOTH/mod.log`.

## ⚠️ Важно
Мод — **бета**, в GTA его запуск ещё не проверялся. Если что-то отвалится — это ожидаемо, фиксируй и присылай детали.
