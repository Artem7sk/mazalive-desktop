# Восстановление после ошибки

## A. Приложение не запускается / белый экран
1. Перезапусти приложение.
2. Если не помогло — **Восстановление приложения**:
   - Windows: «Параметры → Приложения → Mazlive Desktop → Изменить → Восстановить».
3. Обнови до последней беты (кнопка «Проверить обновления»).

## B. GTA не найдена
- Нажми **Проверить GTA** → укажи папку с `GTA5.exe`.
- Убедись, что это **Legacy**, а не Enhanced.

## C. Мод не установлен / сломан
1. Закрой GTA.
2. **Удалить мод**, затем **Установить мод** заново.
3. Если файл «изменён пользователем» — сначала верни оригинал из `backups/` (см. UNINSTALL.md), затем переустанови.

## D. Агент не подключается
- Проверь интернет.
- В панели должно быть «Соединение с MazLive: подключено». Если нет — закрой и снова **Запустить** игру.
- Убедись, что стрим подключён в дашборде (иначе комната пустая).

## E. События не приходят
- Проверь, что **эфир активен** (панель: Эфир = LIVE).
- Проверь статус мода (`phase=running`, нажми F7 в GTA).
- Если мод офлайн — перезапусти GTA.

## F. Мод завис / не реагирует
- Жди: команды старше 30 с мод игнорирует (защита).
- Нажми **Очистить** / **Сброс** в панели.
- Если не помогло — закрыть GTA (F10), перезапустить мод и игру.

## G. Откат мода на предыдущую версию
1. В `backups/` найди бэкап DLL.
2. Скопируй обратно в `scripts/MazLiveKOTH.dll`.
3. Перезапусти GTA.

## H. Полный сброс (крайний случай)
1. Закрой приложение и GTA.
2. Удали папку `<GTA>/scripts/MazLiveKOTH/` целиком (в ней только данные мода).
3. Удали `<GTA>/scripts/MazLiveKOTH.dll`.
4. Переустанови мод через приложение.

## Логи для диагностики
- Мод: `<GTA>/scripts/MazLiveKOTH/mod.log`
- Статистика мода: `<GTA>/scripts/MazLiveKOTH/stats.txt`
- Панель приложения: вкладка «Журнал».
