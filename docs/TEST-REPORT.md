### Что именно покрывают тесты
- **Дедупликация**: повторная доставка того же события игнорируется; два разных подарка одного
  зрителя за одну мс не схлопываются (ключ учитывает `giftId`).
- **Лимиты**: ≤12 объектов/событие, очередь ожидающих ACK ≤100.
- **streak-подарки** (`giftType=1`): учитываются только при `repeatEnd=true`.
- **Санитизация имени**: управляющие символы/`~`/`\n` удаляются, обрезка до 40.
- **Подписка**: `firstTime=false` игнорируется; повторный follow от того же uid — игнор.
- **Мост**: атомарная запись, path-injection отклоняется, stale status (>5с) отклоняется,
  protocol mismatch отклоняется, «Queue full» при 100 файлах.
- **Агент**: `join_room` с правильным payload, токен только в памяти, `disconnect()` стирает токен,
  команды не уходят при `phase!=running`, ACK обрабатываются, `stream_stopped` чистит очередь.

## ⏳ НЕ проверено (требуется твой ПК, Windows)

| Что | Почему |
|---|---|
| Реальный запуск мод-а **в GTA V** | `runtimeTested: false`; на сервере Linux, без GTA |
| PowerShell INSTALL/UNINSTALL «в бою» | только логика, не прогонялся на Windows |
| Захват окна GTA в TikTok Live Studio | требует эфира и GTA |
| Живой Socket.IO с реальным TikTok-эфиром | требует активного стрима |
| electron-updater (скачивание апдейта) | требует опубликованного релиза |
| Сборка EXE | выполняется в GitHub Actions при пуше тега |

## 🧪 Сценарий проверки на Windows

## ⚠️ Известные ограничения беты

1. Мод в GTA ещё не запускался — это бета.
2. Требуется GTA **Legacy**, не Enhanced.
3. Панель — внутри Electron (IPC), без внешнего HTTP-сервера (по решению Артёма).
